Complete Technical Specification · Database Design · API Architecture · Development Roadmap

📌 Description

A comprehensive, production-ready SaaS portfolio web application for Arsalan Akhtar (Full-Stack Software Engineer). Showcases projects, services, blogs. Users can browse, add to cart, place orders with mock Stripe payments, rate/review, manage profiles. Admin has full control over all content, users, orders, promo codes, analytics, AI chatbot. Trilingual (EN, UR, AR), light/dark themes, fully responsive across all devices.

🎨 Design Direction

Upwork-Inspired with Custom Theme

Professional, clean layout inspired by Upwork's UI patterns — card-based layouts, clear hierarchy, structured tables — with a distinctive purple + light blue + black + gray gradient theme. No default blue/purple cliché.

Security Measures

  • JWT httpOnly Cookies: Access (15min) + Refresh (7d) — not in localStorage
  • Bcrypt: 12 salt rounds for all passwords
  • Redis Rate Limiting: Per-IP + per-user (100 req/15min public, 200 auth)
  • Helmet.js: Security headers (CSP, X-Frame-Options)
  • CORS: Strict origin whitelist
  • Input Validation: All inputs validated server-side
  • OTP: 30s in Redis, auto-deleted. Resend invalidates previous
  • 2FA: After login, if enabled → require OTP before tokens
  • Route Protection: JWT check + role check. Direct URL blocked
  • Complete Logout: Clear httpOnly cookies + Redis sessions
  • No SQL Injection: Mongoose ODM only
  • XSS Protection: React auto-escape + server sanitization
  • File Upload: Multer limits + type validation + Cloudinary transforms
  • Env Vars: All secrets in .env, never in git

Features Detail

Auth & 2FA Flow
Signup Send Verify Email Click Link Auto Login
Login 2FA? Send OTP (Email/SMS/WA) Verify OTP Tokens
2FA OTP Priority: If mobile exists → send to mobile + WhatsApp + email. If no mobile → email only. 30s TTL in Redis.
Forgot Password: Check mobile first → if found, send OTP there. If not → check email. If neither → error.
Admin Features
  • DataTable: Search, filter, sort, pagination, bulk actions, "Showing 1 of 10"
  • Detail Pages: Click row → detail with all info, pictures, videos, skills, tech, reviews
  • Cloudinary Dedup: Hash check, skip duplicates, auto-cleanup on delete
  • Orders: Send email modal, delete ONLY "sent", delete-all skips "not sent"
  • Promo Codes: Auto-qualify users based on purchase, send via SMS/WA/email, per-user limit
  • Dashboard: Metrics, charts, recent activities
  • Country/City Cascade: Select country → city dropdown filters, auto country code
User Features
  • Guest: Home, projects, services, about, contact, blogs, gallery, resume
  • Login Required: Wishlist, cart, checkout, orders, pay, reviews, profile
  • Cart Flow: Add → checkout → Stripe (mock) → place order (paid/pending)
  • Promo: Validate at checkout, usage limit warning modal
  • Order Notification: Admin sends email → user gets WhatsApp notification
  • Profile: Edit info, avatar, password, country→city cascade
Public Pages
  • Home: Banner slider, top projects, top services, categories, skills, stats, CTA
  • Projects/Services: Grid, filters (category, tech, skill, rating), search, sort, pagination
  • Detail: Gallery, info, metadata, related, reviews, cart/wishlist, live preview

i18n & Theme
Internationalization

i18next + react-i18next. Translation JSON for EN, UR, AR. Language switcher in navbar. Urdu/Arabic = RTL (document.dir + document.lang update dynamically). Backend stays English — translation is frontend-only.

Light/Dark Theme

CSS custom properties in :root (dark) and [data-theme="light"]. Toggle in navbar. Saved in localStorage + Redux. 0.4s smooth transition.
