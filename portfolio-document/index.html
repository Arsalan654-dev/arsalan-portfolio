Arsalan Akhtar Portfolio SaaS Web App

Complete Technical Specification, Database Design, API Architecture & Development Roadmap

Description

A comprehensive, production-ready SaaS portfolio web application for Arsalan Akhtar (Full-Stack Software Engineer). Showcases projects, services, blogs. Users can browse, add to cart, place orders with mock Stripe payments, rate/review, manage profiles. Admin has full control over all content, users, orders, promo codes, analytics, AI chatbot. Trilingual (EN, UR, AR), light/dark themes, fully responsive across all devices.

Design Direction

Upwork-Inspired with Custom Theme

Professional, clean layout inspired by Upwork's UI patterns — card-based layouts, clear hierarchy, structured tables — with a distinctive purple + light blue + black + gray gradient theme. No default blue/purple cliché.

Database Schemas (13 Collections)

5.1 — User Collection
Mongoose Schema — users
{
  _id:              ObjectId,
  name:              { type: String, required: true, trim: true, min: 2, max: 100 },
  email:             { type: String, required: true, unique: true, lowercase: true },
  password:          { type: String, required: true, min: 8 },  // bcrypt
  role:              { type: String, enum: ["admin","user"], default: "user" },
  isEmailVerified:   { type: Boolean, default: false },
  isActive:          { type: Boolean, default: true },
  is2FAEnabled:      { type: Boolean, default: false },
  profilePicture:    { type: String, default: null },  // Cloudinary URL
  mobileNumber:      { type: String, default: null, sparse: true },
  country:           { type: ObjectId, ref: "countries", default: null },
  city:              { type: ObjectId, ref: "cities", default: null },
  address:           { type: String, default: null, max: 500 },
  wishlist:          [{ type: ObjectId, ref: "projects" }],
  cart:              [{
    item:     { type: ObjectId, refPath: "itemType" },
    itemType: { type: String, enum: ["projects","services"] },
    quantity: { type: Number, default: 1 },
    addedAt:  { type: Date, default: Date.now }
  }],
  totalPurchasedAmount: { type: Number, default: 0 },
  promoCodesReceived:  [{ type: ObjectId, ref: "promocodes" }],
  createdAt:         { type: Date, default: Date.now },

}

Security Measures

  • JWT httpOnly Cookies: Access (15min) + Refresh (7d) — not in localStorage
  • Bcrypt: 12 salt rounds for all passwords
  • Redis Rate Limiting: Per-IP + per-user (100 req/15min public, 200 auth)
  • Helmet.js: Security headers (CSP, X-Frame-Options)
  • CORS: Strict origin whitelist
  • Input Validation: All inputs validated server-side
  • OTP: 30s in Redis, auto-deleted. Resend invalidates previous
  • 2FA: After login, if enabled → require OTP before tokens
  • Route Protection: JWT check + role check. Direct URL blocked
  • Complete Logout: Clear httpOnly cookies + Redis sessions
  • No SQL Injection: Mongoose ODM only
  • XSS Protection: React auto-escape + server sanitization
  • File Upload: Multer limits + type validation + Cloudinary transforms
  • Env Vars: All secrets in .env, never in git

2FA OTP Priority: If mobile exists → send to mobile + WhatsApp + email. If no mobile → email only. 30s TTL in Redis. Resend invalidates previous.
Forgot Password: Check mobile first → if found, send OTP there. If not → check email. If neither → error "Email or mobile not found".
9.2 — Admin Features
  • Reusable DataTable: Search (configurable fields), filter (configurable + reset), sort (newest/recent/older), pagination (numbers + prev/next + "Showing 1 of 10"), bulk actions
  • Detail Pages: Click row → detail page. Projects/Services show: all info, pictures, videos, skills, tech, slugs, category, reviews, ratings
  • Cloudinary Dedup: Before upload, check hash. If identical → skip upload, delete dup. On update: remove orphaned. On delete: remove all associated
  • Orders: Send email (modal: email + body + file attach). Delete ONLY "sent". Delete-all skips "not sent". Send button hidden if "not paid"
  • Promo Codes: On create → find users where totalPurchased >= minAmount → add to qualified → send via mobile/whatsapp/email. Per-user limit tracked. If limit reached → modal warning
  • Dashboard: Metrics cards + charts (orders over time, revenue, top items, user growth, ratings distribution) + recent activities
  • Country/City Cascade: Select country → city dropdown filters. Mobile input shows readonly country code
  • User Creation: Admin creates → verification email sent. CANNOT change user's password or email
9.3 — User Features
  • Guest Access: Home, projects, services, details, about, contact, blogs, gallery, resume download
  • Login Required: Wishlist, cart, checkout, orders, pay, rate/review, profile
  • Cart Flow: Add items → checkout → optional Stripe payment → place order (can be "not paid") → pay later from orders
  • Promo at Checkout: Enter code → validate → see discount → apply. Limit reached → warning modal
  • Order Notification: Admin sends email → user gets WhatsApp "Order sent to your email"
  • Profile: Edit info, avatar, password. Country → City cascade
9.4 — Public Pages
  • Home: Banner slider, top projects, top services, categories, skills, stats, CTA
  • Projects/Services: Grid, filters (category, tech, skill, slug, rating), search, sort, pagination
  • Detail: Gallery, info, metadata, related items, reviews, cart/wishlist (login check), live preview
  • Contact: Form (name, email, subject, message) → no login needed
  • AI Chatbot: Floating widget, OpenAI API, admin-configurable instructions
9.5 — i18n & Theme
Internationalization

i18next + react-i18next. Translation JSON for EN, UR, AR. Language switcher in navbar. Urdu/Arabic = RTL (document.dir + document.lang update dynamically). Backend stays English — translation is frontend-only.

Light/Dark Theme

CSS custom properties in :root (dark) and [data-theme="light"]. Toggle in navbar. Saved in localStorage + Redux. 0.4s smooth transition. All components use variables only.
